# E255｜模型越来越强，为什么用户没感觉？再访阿里国际站总裁张阔


## Key Points

- 阿里国际站总裁张阔半年后再次做客硅谷101：核心问题不是标题暗示的「模型越来越强用户没感觉」，而是电商垂直 Agent 如何从「AI 搜索」演化为跨平台经营的一站式 Agent。
- 团队基于 Alibaba.com 与 Accio 上百万条真实经营数据，整理出 107 个电商任务（L1-L4 难度分级）并开源；最前沿模型在无人干预条件下的通过率只有 61% 出头。
- 跑完全部任务成本对比：Accio Work 约 3.69 美元，Codex 与 Claude Code 均 9 美元以上——约三分之一。
- 张阔的框架 Agent = Model × Harness × Context 是乘法：任何一项为 0，整体结果就是 0；Model 与 Harness 必须联合优化，Context 是阿里 20 多年电商/跨境/采购数据的天然优势。
- 成本优势来自帕累托最优路由：L3 以下的任务用小尺寸或高性价比模型，多模态/视频任务路由到特定模型，加上集约采购与 harness 效率。
- 人保留最终判断：支付与采购按钮、交易条款是否执行、想法是不是真问题、客户群基数与溢价意愿、budget 在广告/库存/渠道/margin 之间的取舍。
- 产品路径三阶段：AI 搜索（整体搜索 +20%，多模态搜索 +130%）→ Sourcing 前后延展（agentic trade）→ 2026 年 4 月推出 Accio Work（跨平台管理电商后台）。
- 「商业 AGI」定义：在预算与供应链给定的边界内，用这个 Agent 经营一定比人做得更赚钱。

## Overview

半年后再访阿里国际站总裁张阔，讨论电商垂直 Agent 从「AI 搜索」到一站式经营 Agent 的演进。张阔用 107 个自建电商任务基准（前沿模型无人干预通过率仅 61%）量化了通用榜单 99 分与真实经营之间的落差，并给出 Agent = Model × Harness × Context 的乘法框架、帕累托最优的模型路由与成本逻辑（Accio Work 成本约为通用 Agent 的三分之一），以及哪些决策必须留给人。节目还对比了中美 SaaS 生态、多平台经营与客服/ToB 预警等高频用例。


## Implications

对做垂直 Agent 的产品团队：通用榜单高分与业务可用性之间存在尚未闭合的鸿沟，自建基准 + 端到端成本是关键指标；模型商品化背景下，harness 工程与 context 才是护城河。对企业：可路由的小模型 + 定制 harness 往往比 fine-tune 更划算；人应保留支付、采购与商业判断等最终决策权。
